# AIBox Mac

Codex 藍牙閃燈與搖動開啟對話專案的 Mac 端程式庫。

## 目標流程

AI 當次回覆／輪次結束 → Mac 通知 BLE 裝置閃光 → 使用者搖動裝置 → Mac 將 Codex 帶到前景並開啟對應對話。

「完成」指當次回覆／輪次結束，不需要判斷整個任務或需求是否完成。

## 規劃技術與職責

- 語言：Swift。
- 開發工具：Xcode。
- BLE 通訊：CoreBluetooth。
- 取得 Codex 回覆結束事件及對話 ID。
- 傳送閃燈指令至裝置。
- 收到裝置的搖動事件後，開啟對應的 Codex 對話。

裝置端程式庫位於同層的 `aibox-firmware`。

## 目前狀態

目前僅初始化 Git 程式庫與文件，尚未建立 Xcode 專案或實作功能。

依專案交接資訊，後續預計驗證 Codex 的 `agent-turn-complete` 通知、`thread-id`／`turn-id` 資料，以及 `codex://threads/<thread-id>` 深層連結。目前桌面版的實際通知觸發、背景喚回與對話定位尚未實測。

多個對話完成時的對應與選擇規則尚未決定；「只保留最後完成的對話」不是已確認的產品行為。

本程式庫初始化不包含開發環境安裝、Codex 設定修改或整合測試。
